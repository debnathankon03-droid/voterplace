# Election Glossary

| Term | Full Form | Definition |
|------|-----------|------------|
| ECI | Election Commission of India | Constitutional body that conducts elections |
| EVM | Electronic Voting Machine | Device used for casting votes electronically |
| VVPAT | Voter Verifiable Paper Audit Trail | Paper trail attached to EVM for vote verification |
| EPIC | Electors Photo Identity Card | Official voter ID card issued by ECI |
| NOTA | None of the Above | Option to reject all candidates |
| NVSP | National Voter Service Portal | Online portal for voter services |
| MCC | Model Code of Conduct | Guidelines for parties during elections |
| BLO | Booth Level Officer | Officer assigned to maintain voter rolls at booth level |
| ERO | Electoral Registration Officer | Officer responsible for voter registration |
| RO | Returning Officer | Officer managing elections in a constituency |
| DEO | District Election Officer | Officer managing elections at district level |
| CEC | Chief Election Commissioner | Head of the Election Commission |
| FPP | First Past the Post | Electoral system where highest votes wins |
| PwD | Persons with Disabilities | Voters with physical/mental disabilities |
| Form 6 | New Voter Registration | Application to register as a new voter |
| Form 7 | Objection to Inclusion | Application to remove a name from voter list |
| Form 8 | Correction of Entries | Application to correct voter list details |
| Lok Sabha | House of the People | Lower house of Indian Parliament (543 seats) |
| Rajya Sabha | Council of States | Upper house of Indian Parliament (245 seats) |
| Vidhan Sabha | Legislative Assembly | State-level legislative body |
| Constituency | Electoral District | Geographic area that elects one representative |
| Polling Station | Voting Booth | Location where voters cast their ballots |
| Electoral Roll | Voter List | Official list of eligible voters |
| Indelible Ink | Voter's Ink | Ink applied to finger to prevent double voting |
| cVIGIL | Vigilant Citizen | App for reporting election code violations |
| Tendered Ballot | Challenged Vote | Paper ballot given when someone has already voted in your name |
| Postal Ballot | Absentee Vote | Ballot sent by mail for those unable to visit polling station |
| Mock Poll | Test Run | Trial run of EVMs before actual voting begins |
